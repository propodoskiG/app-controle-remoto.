# 📱 App Controle Remoto

> Aplicativo de controle remoto via Bluetooth para movimentação do robô LEGO MINDSTORMS NXT.

---

## 🎯 Objetivo
Controlar os movimentos de um robô LEGO MINDSTORMS NXT remotamente pelo celular. O aplicativo permite manobrar o robô de forma intuitiva, enviando comandos de direção via conexão sem fio (Bluetooth).

## ✨ Funcionalidades
- 🔌 **Conexão Bluetooth:** Comunicação direta e sem fio entre o aplicativo e o bloco NXT.
- 🕹️ **Controle por pressão:** O robô acelera e se move enquanto o botão direcional está sendo pressionado e para automaticamente assim que o botão é solto.
- ⬆️⬇️⬅️➡️ **Botões direcionais:** 4 botões para controlar a movimentação (Frente, Trás, Esquerda e Direita).
- 🛑 **Botão de Parar:** Botão extra de parada na interface (funcionalidade em desenvolvimento).

## 🛠️ Tecnologias Utilizadas
- **MIT App Inventor** (Desenvolvimento em blocos)
- **GitHub** (Hospedagem do projeto)
- **LEGO MINDSTORMS NXT** (Hardware)

## 📂 Como testar este aplicativo?
1. Baixe o arquivo `.aia` disponível neste repositório.
2. Acesse o [MIT App Inventor](http://ai2.appinventor.mit.edu/).
3. Clique em **Projetos > Importar projeto (.aia) do meu computador**.
4. Selecione o arquivo baixado para visualizar e testar o código!

⚠️ **Aviso de Teste Físico:** Para testar o aplicativo diretamente no robô, lembre-se de ativar o Bluetooth do seu smartphone e pareá-lo com o bloco NXT antes de realizar a conexão pelo app.
